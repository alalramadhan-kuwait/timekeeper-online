# Paper motion videos

Turns a script into a 9:16 explainer in a cut-paper style: every shape is paper with fibre texture, hand-cut edges and a drop shadow, characters are blocky cardboard figures, and a taped paper banner carries the one-line takeaway of each scene while word tags pop onto the floor in time with the voice.

How it works: a storyboard JSON describes scenes. `engine/` draws them as DOM driven only by time. `scripts/render.mjs` steps time in headless Chromium, screenshots every frame, and ffmpeg encodes the MP4 and mixes audio. Nothing is generated by a model, so a render is repeatable and any frame can be previewed in seconds.

Read `references/style-guide.md` before writing a storyboard (it describes the original playful look; the Documentary and brand mode section below describes the restrained one). Read `references/elements.md` for every element and its options. `examples/demo.json` is a complete 5-scene storyboard.

## Workflow

1. **Break the script into beats.** One idea per scene, 2 to 6 seconds each, 5 to 12 scenes. Write the banner first: a takeaway of 6 words or fewer, uppercase renders best. Then the spoken line.
2. **Pick a visual metaphor per beat** from the element library (dial for levels, stopwatch for time, books for output, skyline for scale, meter for usage, stamp for a verdict, list for a recap). Keep the mascot present in most scenes and change its outfit and face to show progress or mood.
3. **Write `storyboard.json`.** Start by copying `examples/demo.json`. Times inside a scene are scene-local seconds.
4. **Preview before rendering.** Stills and a contact sheet take seconds.
   ```bash
   node .claude/skills/paper-motion/scripts/render.mjs story.json --sheet --every 2 -o sheet.png
   node .claude/skills/paper-motion/scripts/render.mjs story.json --still 1.5,6 --scale 1.5 -o stills/
   ```
   Open the PNGs and check the QA list below. Fix, re-run, repeat.
5. **Add audio** (optional, see Audio).
6. **Render.** `node .claude/skills/paper-motion/scripts/render.mjs story.json -o out.mp4 --scale 1.5` gives 1080x1920. About 25 seconds of video takes about a minute at 720p on 4 workers.
7. **Verify and deliver.** Check duration and size with `ffmpeg -i out.mp4`, view a few frames, and send the file to the user. Say plainly if audio was not added.

## Storyboard

```json
{
  "width": 720, "height": 1280, "fps": 30,
  "audio": { "voice": "vo.wav", "music": "bed.mp3", "musicGain": -18 },
  "scenes": [
    {
      "dur": 4.5,
      "theme": "teal",
      "banner": "Clock in with one tap",
      "captions": "Every shift | starts with one tap",
      "transition": "slide",
      "elements": [
        { "type": "dial", "x": 360, "y": 470, "labels": ["IN","BREAK","OUT"], "value": [[0.6,0],[1.7,1,"outBack"]], "in": {"type":"pop","at":0.3} },
        { "type": "mascot", "x": 360, "y": 960, "gear": "headband", "look": "happy", "idle": "bob", "in": {"type":"rise","at":0.1} }
      ]
    }
  ]
}
```

- **Canvas** is 720x1280 design pixels. `--scale` multiplies the output size. The floor starts at y 960, captions sit at y 1004, the banner centre is y 215. Keep the action between y 260 and 960.
- **Scene fields:** `dur` (seconds, or `"auto"` when `voice` is set), `theme`, `banner`, `captions` or `words`, `transition` (`slide`, `push`, `rise`, `drop`, `fade`, `cut`), `floor` (false for full-bleed), `elements`. Omit `banner` to keep the previous one across a cut.
- **Themes:** teal, navy, night, dusk, rust, cream, sage, mustard, plum, stone, or an object `{bg, blot:[light,dark], floor, floorTop}`.
- **Camera:** a scene can move like a shot: `"camera": {"zoom": kf, "x": kf, "y": kf}` (keyframes like any value; x/y is the point the camera looks at, zoom 1 = the plain stage). Each element's `depth` sets how much the move affects it: `0` pinned to the screen (plates, overlays), `<1` far layers that drift slower (sky, mountains), `1` the scene plane, `>1` foreground that sweeps past (a pen, a gear, a mic) for parallax. Lay a wide set wider than 720 and pan across it. Use `floor: false` and draw your own ground when the camera moves, since the floor strip stays put.
- **Figures:** `cutout` takes `flip: true` to mirror a person so two can face each other; walk them in with `x` keyframes plus a `bob` idle limited by `from`/`until`; crop them waist-up by making `h` large and putting the bottom below the frame.
- **Reveal:** `{"type": "reveal", "src": …, "reveal": kf 0..1}` uncovers an image clockwise like a sweeping hand (logo endings).
- **Captions:** `captions` is plain text spread over the scene by word length. Put `|` between phrases to force a new group. Groups hold up to 3 words. For exact sync use `words: [[0.4,"Every"],[0.7,"shift"], ...]` from a forced aligner or your own timing. `captionStart`/`captionEnd` squeeze the words into a window; the last group stays up until the scene ends unless `captionClear` (scene seconds) takes it off sooner, e.g. before a wordless montage.
- **Any element** takes `x`, `y`, `rot`, `scale`, `opacity`, `z`, `anchor`, `behind` (draw under the floor), `in`/`out` (`pop`, `rise`, `drop`, `slideL/R/U/D`, `slam`, `flip`, `grow`, `fade`), `idle` (`bob`, `float`, `sway`, `wiggle`, `pulse`, `hop`, `spin`, `shake`), and keyframes on any number: `"x": [[0,100],[2,400,"inOutCubic"]]`.
- **Right to left:** nothing to set. Arabic text is detected per caption group and the Cairo font is used. Add `"dir": "rtl"` at the top level to force right-to-left caption order.

## Documentary and brand mode

For a serious, brand-led film (not a playful explainer) the same engine switches to a restrained look and adds evidence handling.

- **Brand theme.** Top-level `style` overrides the banner (`paper`, `ink`, `upper`, `tape`, `torn`, `size`), the captions (`font`) and the grain and vignette. `themes` defines custom wall and floor colours with `capBg` and `capInk` for the caption tags. A worked example is `video/success-story/tk-style.json` in this repo. Never invent a brand colour: use only what the logo and brand material show.
- **Real evidence over art.** The `photo`, `igpost`, `phone`, `door`, `laptop` and `image` elements take `"asset": "some_id"`. If a file `assets/some_id.jpg|png|webp` sits next to the storyboard it is used, otherwise a loud "REAL PHOTO NEEDED" placeholder shows. Render prints the placeholders that remain, and `--final` refuses to run while any do.
- **Truth status per scene.** Give every scene `id`, `status` (`CONFIRMED`, `FOUNDER`, `METAPHOR`, `UNCONFIRMED`), `claims`, and `note`. `--review` stamps the status on every frame so reviewers can see it. `--final` refuses scenes with no status. Project scripts can audit further (see `video/success-story/check-story.mjs`, which also classifies watch-house relationships and blocks partnership wording).
- **Sound.** `scripts/make-sfx.py` writes a procedural kit to `assets/sfx/` (tick, tock, paper slide, tear, tape, stamp, shutter, crown winding, clasp, plane, notification, mic tap, door chime, crowd, room). Per scene: `"sfx": [{"at": 1.2, "name": "stamp", "gain": -6}]`, `"beds": [{"name": "watch_run", "from": 0, "to": 4, "gain": -22}]`, and `"silent": true` to switch off the automatic paper sounds for deliberate silence. Transitions and banners get paper sounds automatically. The mix is loudness-normalised. `scripts/make-score.py` makes a temporary score (curious, momentum, scale) for pacing review only; replace it with real music.
- **Map element.** Real country and US-state outlines (Natural Earth, built by `scripts/build-geo.mjs` into `assets/geo/world.json`). Keyframe the view to zoom, add pins and animated plane routes, highlight countries, and unfold the sheet.
- **Founders as puppets.** The `puppet` element is an articulated paper rig (head, torso, upper and lower arms, hands, thighs, shins, feet) with named poses and a side-view walk cycle at 12 fps. Without art it draws a plain stand-in; with `"character": "id"` it loads `assets/characters/<id>/front|side/<part>.png` automatically.

## Audio

The engine does not synthesise speech. Bring the audio:

- **Best sync: one clip per scene.** Put `"voice": "scene3.wav"` on each scene and omit `dur`. The scene is exactly as long as the clip plus 0.45 s, the clip starts 0.15 s in, and captions auto-time to the same length. Generate the clips with whatever voice tool the user has (a recorded read, a text-to-speech service, or an audio generation tool connected to the session). Do not claim a specific tool is available without checking.
- **One long voice-over:** `--audio vo.wav` or `audio.voice`, then set scene `dur`s to match and use `words` timings. The renderer warns if the audio is longer than the video.
- **Music bed:** `--music bed.mp3` loops, fades in and out, and sits 18 dB under the voice (`musicGain`).
- The reference style is voice-led with continuous audio. A silent render is a draft, not the deliverable.

## QA checklist (do this on the stills)

- Banner fits on one line and is readable; no clipped text anywhere.
- Nothing important sits below y 960 except captions, or above y 260.
- Each scene has one clear focal prop plus the mascot. If it looks busy, remove a prop.
- Mascot feet stand on the floor line. Overlaps between props and the mascot head are deliberate.
- Captions match the voice words. Groups are 1 to 3 words.
- Contrast: cream or white text on dark paper, near-black on light paper.
- Neighbouring scenes use different themes so the slide transition reads.

## Brand and content rules

- The reference video that defined this style used a third party's logo and mascot. This skill deliberately ships a generic mascot and no logos. Use the user's own brand through the `image` element (logo on a banner or prop) and custom theme colours. Do not recreate someone else's marks.
- Text in the video must be true to the script the user gave. Do not invent numbers, prices or claims.

## Setup and troubleshooting

- Needs Node 18+, Chromium and ffmpeg. The script finds Chromium in `/opt/pw-browsers`, and installs `playwright-core` into `~/.cache/paper-motion` on first run. For ffmpeg it uses `ffmpeg` on the path, `$FFMPEG`, or `pip install imageio-ffmpeg`.
- Fonts are bundled in `assets/fonts` (SIL OFL), so renders work offline.
- Slow? Use `--workers 4`, drop `--scale`, or render a range with `--from 4 --to 9`.
- An unknown element type or bad JSON stops with a message naming the problem. A `page error:` line means a bug in the storyboard values.
- Add a new prop by writing a builder in `engine/props.js` (`B.name = (spec, ctx) => ({ node, w, h, update })`) using `PM.piece()` for paper pieces, or draw it inline with the `svg` and `html` elements.
